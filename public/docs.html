Подключение приложения

FlowID работает как обычный OpenID Connect провайдер: любая библиотека, которая умеет authorization code с PKCE, подключается по адресу метаданных без ручной настройки.

Шаг 1. Зарегистрируйте приложение

В кабинете на вкладке «Разработчику» создайте приложение и укажите redirect URI. Секрет показывается один раз — сохраните его сразу.

Создать приложение

Шаг 2. Отправьте человека на вход

GET /oauth/authorize
  ?response_type=code
  &client_id=flow_…
  &redirect_uri=http://localhost:4000/callback
  &scope=openid profile email
  &state=случайная строка
  &code_challenge=BASE64URL(SHA256(verifier))
  &code_challenge_method=S256

Для публичных клиентов PKCE обязателен. prompt=login заставит человека войти заново, prompt=consent — снова показать экран разрешений.

Шаг 3. Обменяйте код на токены

const response = await fetch('http://localhost:3000/oauth/token', {
  method: 'POST',
  headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
  body: new URLSearchParams({
    grant_type: 'authorization_code',
    code,
    code_verifier: verifier,
    redirect_uri: 'http://localhost:4000/callback',
    client_id: clientId,
    client_secret: clientSecret // только для серверных приложений
  })
});

В ответе придут access_token, id_token и, если запрошен scope offline_access, refresh_token. Повторное использование кода отзывает все выданные по нему токены.

Шаг 4. Проверьте id_token

Подпись — RS256, открытый ключ лежит в /oauth/jwks.json. Проверьте iss, aud, exp и nonce, если отправляли его. Данные профиля можно и запросить: GET /oauth/userinfo с заголовком Authorization: Bearer ….
