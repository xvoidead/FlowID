Вход, который вы не пишете заново

FlowID берёт на себя регистрацию, пароли, сессии и вход через VK ID, а вашему приложению отдаёт токены по стандартам OAuth 2.1 и OpenID Connect.

Что уже работает

Ничего не нужно докручивать перед первым входом: сервер, база и экраны идут вместе.

Пароли по-взрослому

scrypt с солью, проверка слабых паролей, сброс по ссылке из письма и отзыв чужих сессий после смены.

VK ID из коробки

Вход через VK с PKCE, привязка профиля к существующему аккаунту и отвязка, когда она больше не нужна.

Сессии на виду

Человек видит все входы: браузер, систему, адрес и время. Любой можно завершить в один клик.

Свои приложения

client_id и секрет выдаются в кабинете. Redirect URI сверяются посимвольно, секрет можно перевыпустить.

Эндпоинты

Полный набор лежит по адресу /.well-known/openid-configuration — большинству библиотек достаточно его одного.

АдресЗачем
GET /oauth/authorizeНачало входа, выдаёт код
POST /oauth/tokenОбмен кода на токены, обновление
GET /oauth/userinfoПрофиль по access-токену
GET /oauth/jwks.jsonКлючи для проверки id_token
POST /oauth/revokeОтзыв выданного токена
 
# обмен кода на токены
curl -s http://localhost:3000/oauth/token \
  -d grant_type=authorization_code \
  -d code=$CODE \
  -d code_verifier=$VERIFIER \
  -d redirect_uri=http://localhost:4000/callback \
  -u "$CLIENT_ID:$CLIENT_SECRET"
